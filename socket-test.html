How to use this demo

  1. Log in as two different users through your ScaleChat REST API.
  2. Copy each user's access token into the respective field above.
  3. Click Connect for both users. They automatically join the prefilled conversation.
  4. Send a message from User A and watch it appear in User B's chat.
  5. Start typing in either chat and observe the other user's typing indicator.
  6. Watch the message status change from Sent to Delivered and Read.
  7. Try disconnecting one user to observe the connection behaviour.

Tip: Keep both chat windows visible so you can observe events on both sides.
