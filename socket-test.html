How to use this demo

  1. Register or log in as two different users through the ScaleChat REST API.
  2. Paste each user's access token into the matching field.
  3. Click Connect for both users. Each socket automatically joins the conversation.
  4. Send messages from either side. The other chat window should receive them in real time.
  5. Start typing to see the other user's typing indicator.
  6. Observe delivery, read and presence events in the message status and developer logs.
  7. Disconnect one user to test the presence update.

This is a local development client, not a production chat frontend. Keep access tokens private and do not deploy this page.
